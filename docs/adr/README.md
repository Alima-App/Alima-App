# Architecture Decision Records (ADR)

Gunakan ADR untuk keputusan yang mengubah stack, alur keamanan, skema, storage, autentikasi, atau cara deployment.

Buat file baru dengan format `NNNN-judul-singkat.md`.

## Template

```markdown
# ADR-NNNN: Judul keputusan

- Status: Proposed | Accepted | Rejected | Superseded
- Tanggal: YYYY-MM-DD

## Konteks
Masalah atau kebutuhan yang memerlukan keputusan.

## Keputusan
Pilihan yang disepakati.

## Alternatif
Pilihan lain yang dipertimbangkan.

## Konsekuensi
Dampak positif, risiko, biaya pemeliharaan, dan pekerjaan migrasi.

## Validasi
Cara menguji bahwa keputusan berjalan dan aman.
```
