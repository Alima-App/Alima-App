## 4. Rincian perbaikan

### Kode (folder `js/`)

- **`js/utils.js` (baru):** `escapeHtml`, `safeHttpUrl` (hanya `http:`/`https:`), `buatKodeKelas`
  (`crypto.getRandomValues`, selalu 6 karakter `[A-Z0-9]`), `formatTanggal`, `getInitials`.
- **`js/pages/kelas.js`:** semua output di-escape; setelah buat/gabung/hapus/keluarkan halaman dirender ulang
  langsung; pembuatan kelas mengulang dengan kode baru hanya saat terjadi bentrok kode (error `23505`);
  tanggal gabung memakai `anggota_kelas.joined_at`; hapus kelas menghapus file materi dari Storage **lebih dulu**
  (policy Storage mensyaratkan kelas masih ada) lalu menghapus kelas; semua error dicek dan ditampilkan.
- **`js/pages/materi.js`:** semua output di-escape; URL tautan divalidasi saat simpan dan saat tampil;
  `rel="noopener noreferrer"`; ekstensi dan `contentType` ditentukan dari tipe materi; file yatim dibersihkan
  bila insert gagal; hapus materi menghapus baris dulu baru file; unduh membuka jendela secara sinkron;
  `window.location.reload()` diganti render ulang; kode mati `editData` dihapus.
- **`js/router.js`:** navigasi yang bentrok diantrikan; pesan placeholder sesuai mode.
- **`js/providers/supabase-auth.js`:** cache profil kedaluwarsa 10 menit, dicocokkan dengan `user.id`;
  `register` tidak lagi mengirim `peran`.
- **`js/pages/login-production.js`:** pilihan peran dihapus, ditambah catatan bahwa akun dosen dibuat administrator.
- **`js/pages/dashboard-production.js`:** memakai `escapeHtml` bersama; inisial dihitung dari nama mentah.
- **`.github/workflows/ping.yml`:** `permissions: contents: read`, secret lewat `env`, `--max-time 30`.

### Database (`supabase/migrations/20261126090000_harden_answers_grading_storage.sql`)

1. Fungsi `mahasiswa_boleh_menjawab_soal(soal_id)` dan policy `jawaban` INSERT/UPDATE: hanya sebelum
   `batas_waktu`, dan UPDATE hanya selama `nilai IS NULL`.
2. `berikan_nilai_jawaban`: validasi 0–100.
3. `hitung_nilai_pg`: pembandingan `lower(trim(...))`.
4. Policy `anggota_kelompok`: mahasiswa harus anggota kelas yang sama (`WITH CHECK`).
5. Pencabutan EXECUTE `insert_dummy_profile` dari `PUBLIC`, `anon`, `authenticated` bila fungsinya ada.
6. Index unik `kelas_kode_unique_idx` (dilewati dengan NOTICE bila ada duplikat).
7. Bucket `materi-files`: privat, 50 MB, MIME `application/pdf` dan `audio/mpeg`; policy restriktif UPDATE;
   blokir `anon`.

## 6. Cara menerapkan

1. Salin file di paket ini ke repo dengan struktur yang sama (timpa file yang sudah ada), di branch terpisah.
2. Ekspor/backup database Supabase.
3. Jalankan seluruh isi migrasi `20261126090000_...sql` di Supabase SQL Editor. Baca `NOTICE` yang muncul
   (duplikat kode kelas, helper dummy).
4. Jalankan aplikasi dan uji checklist di bawah dengan minimal tiga akun: dosen, mahasiswa terdaftar,
   mahasiswa non-anggota.
5. Setelah lulus uji, merge dan perbarui `SECURITY.md` bila ada temuan baru.
